PIÈCE-SÛRE AI — test du coffre clients

NE PAS DEVINER → VÉRIFIER → DÉCIDER → TRACER

Prototype de test uniquement : n’inscris aucune vraie donnée client. Utilise des noms, coordonnées, véhicules, achats et références entièrement fictifs. N’inscris ni VIN, ni plaque, ni adresse réelle.

Le coffre chiffre les données avant de les enregistrer dans le stockage local du navigateur. Quand la page est déverrouillée, les données sont visibles dans cette page. Une phrase secrète oubliée ne peut pas être récupérée.

Le code de ce test ne contient pas de fonction d’envoi des fiches à un serveur. GitHub Pages héberge néanmoins le code de la page. Ce prototype n’est ni audité ni validé pour stocker de vraies données personnelles. Ne dépose jamais le fichier de sauvegarde dans GitHub.

Créer un coffre de test

Choisis une phrase secrète longue et unique, idéalement plusieurs mots. Ne me l’envoie pas et ne l’inscris pas dans le dépôt GitHub.
