# PIÈCE-SÛRE AI

Application web autonome pour iPad / GitHub Pages.

## Identifiants de démonstration
- Utilisateur : `atelier`
- Mot de passe : `1234`

## Fichiers à placer à la racine du dépôt
- `index.html`
- `manifest.json`
- `icon.svg`
- `.nojekyll`
- `README.md`

## Déploiement sur GitHub Pages
1. Crée un dépôt public sur GitHub.
2. Ajoute les fichiers ci-dessus à la racine.
3. Va dans **Settings** → **Pages**.
4. Choisis **Deploy from a branch**.
5. Branche : `main`
6. Dossier : `/ (root)`
7. Enregistre.

GitHub génère une URL du type :
`https://marcroblin-del.github.io/piece-sure-ai/`

## Installation sur iPad
1. Ouvre l’URL dans **Safari**.
2. Appuie sur **Partager**.
3. Choisis **Sur l’écran d’accueil**.
4. Nomme l’icône : **PIÈCE-SÛRE AI**.
